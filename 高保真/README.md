# 知页 · 高保真页面

## 当前选定的内容页

**[打开内容页 v2 源文件](article-v2.html)** · [对应 UI 规范](../UI规范/内容页-v2.md)

采用已确认截图的布局：左侧全站专题 / 文章目录，中间正文与书本横幅，右上本篇目录，右下提问 / 批注。支持桌面三栏、平板两栏和手机阅读抽屉。

页面依赖同目录 `assets/` 下的 CSS、JavaScript 与 WebP。下载整个目录后打开 `article-v2.html`，或在仓库根目录运行 `python -m http.server 8000`，访问 `/高保真/article-v2.html`。GitHub 的文件页面展示源代码，不是运行中的网页。

提问仅本地演示；批注和收藏保存在当前浏览器，不是账号同步服务。没有接入新的后端接口，也没有替换 `site/` 下的正式站点。
