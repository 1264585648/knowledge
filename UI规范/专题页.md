# 知页 · 专题页高保真规范

版本：2.1 · 专题导航扩展。沿用首页 v2 的颜色、系统字体与交互气质；只增加专题总览与专题文章列表，不做后台或文章正文。

## 页面与入口

- `高保真/topics.html`：全部专题，总览使用双列目录卡片。
- `高保真/topic.html?topic=agent`：具体专题，桌面侧栏用于切换专题，右侧展示文章。
- 首页顶部「专题」、手机导航「专题」及「全部专题」进入总览；首页两张专题卡片直接进入对应专题。
- 「全部专题」返回目录；专题使用独立 query 参数，刷新与分享地址后可以复现所选专题。

## 响应式

- 大于 800px：专题内页显示侧栏；侧栏滚动吸顶，不固定文章区。
- 800px 及以下：侧栏收起，使用「切换专题」展开导航；支持 Esc 和点击外部关闭。
- 640px 及以下：总览单列、手机导航、左右各 20px；卡片内边距 20px；文章摘要 13px / 23px。
- 360px 以下：隐藏非关键的排序提示，标题仍完整换行。
- 手机介绍按两个完整语句换行；不把末尾「阅读」单独挤成一行。

## 原型交互与内容

当前演示包含 6 个专题、21 条唯一文章记录。一条文章可关联多个专题。列表按日期从新到旧排列；专题数量、标题与文章关联集中维护在 `高保真/topics.js` 的 `TOPICS` / `ARTICLES` 中。

总览搜索仅搜索专题名称与介绍；内页搜索仅搜索当前专题下的文章标题与摘要。支持 Ctrl/⌘ + K、方向键、回车、Esc、空态和焦点恢复。命中内页文章后定位列表项；文章正文尚未接入，点击会显示明确的预览提示，不创建虚构正文。

未知专题参数显示「未找到这个专题」；没有文章的专题显示「内容整理中」。专题切换链接使用真实文件名及 query 参数，不依赖本地服务器。显式返回总览通过 sessionStorage 尝试恢复滚动位置，存储不可用时正常降级；浏览器后退沿用原生历史恢复。

## 文件与预览

高保真包含 `index.html`、`topics.html`、`topic.html`、`topics.css`、`topics.js`。下载时请保留同级目录；可从 `index.html` 或 `topics.html` 打开。新专题页通过同目录文件共享样式与交互，没有 CDN、在线字体、第三方图标、外部请求、构建步骤或后端。

首页仅更改 5 个专题入口；原 CSS、原脚本、布局及文章示例保持不变。`UI规范/README.md` 仍是首页 v2 原规范，本文件说明专题扩展与新增边界。
