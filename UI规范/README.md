# 知页 · 首页 UI 规范

**版本：2.0 · 细节精修版**  
**对应实现：[高保真/index.html](../高保真/index.html)**  
**设计范围：首页，以及首页现有的筛选、搜索、手机导航和预览提示状态。**

本版在已确认的首页上调整视觉细节，不改变信息架构。仍然采用居中介绍、浅灰导读、文章列表、双栏专题和轻量页脚。本仓库收录 v2 精修版，规范与高保真分别存放在「UI规范」和「高保真」两个目录。

---

## 01 · 视觉方向

**像一本排版清楚的公开笔记，而不是管理后台或营销落地页。**

以接近白色的画布、中性偏暖灰阶和稳定的文字列线建立秩序。内容保持可读，不依靠缩小字号或极浅灰制造“轻盈”。

不增加大幅封面、英文装饰副标、标签云、计数徽章、渐变、纹理、入场动画或多余操作。默认内容区不使用投影。

### 相比 v1 的关键调整

| 项目 | v1 | v2 |
|---|---|---|
| 颜色气质 | 白底、偏冷深灰 | 近白画布、中性偏暖深灰；导读用浅暖灰 |
| 主标题 | 40px / 700 | 38px / 600；手机保持 30px |
| 区块标题 | 24px | 21px；手机 20px |
| 文章标题 | 16px / 600 | 16px / 500，减轻视觉重量 |
| 桌面摘要 | 跟随不同标题长度起排 | 独立固定起点，所有摘要左边线一致 |
| 桌面文章行 | 最小高度 58px | 最小高度 64px |
| 导航搜索 | 大胶囊底色 | 136 × 34px 轻边框控件，配小型键帽 |
| 专题图标底座 | 56px 圆形 | 44px 圆角方形，图标降至 24px |
| 横向对齐 | 导航、正文、页脚存在光学偏移 | 品牌、正文和页脚文字共用左边线 |
| 悬停 | 主要为颜色变化 | 160ms 轻反馈；箭头移动 2px，正文不动 |
| 手机换行 | 依赖自动平衡换行 | 介绍按语义分句，导读说明按短句换行 |

这些是本项目的设计取舍，不是对 Notion 官方样式的逐项复制。

## 02 · 颜色与语义 Token

HTML 的 `:root` 是视觉参数的唯一入口。不要在新组件中临时加入另一套灰阶。

| Token | 色值 | 用途 |
|---|---|---|
| `--color-page` | `#FEFEFD` | 全页画布，接近白色 |
| `--color-card` | `#FFFFFF` | 专题卡片、搜索弹层、提示浮层 |
| `--color-surface` | `#F6F5F2` | 导读块、轻量选中背景 |
| `--color-surface-hover` | `#F0EFEB` | 导读悬停或按下 |
| `--color-row-hover` | `#F8F8F5` | 文章和专题悬停背景 |
| `--color-heading` | `#2D2E2A` | 标题、站名、当前分类 |
| `--color-text` | `#454640` | 默认正文文字 |
| `--color-muted` | `#6B6D66` | 摘要、元信息、辅助说明 |
| `--color-nav` | `#5E6059` | 导航、次级链接 |
| `--color-border` | `#E8E9E3` | 分隔线、默认边框 |
| `--color-border-strong` | `#CBCDC3` | 搜索和专题悬停边框、弹层边框 |
| `--color-focus` | `#737B65` | 键盘焦点轮廓 |
| `--color-icon` | `#666960` | 常规线性图标 |
| `--color-icon-surface` | `#F3F3EF` | 专题图标底座 |
| `--color-dot` | `#A5A79E` | 装饰性分隔点，不用于正文 |
| `--color-selection` | `#E8EBDF` | 用户选择文字时的背景 |
| `--color-overlay` | `rgb(45 46 42 / 19%)` | 搜索弹层遮罩 |

根据上述色值计算，次级文字与页面背景的对比度约为 **5.20:1**，与默认导读背景约为 **4.81:1**，与导读悬停背景约为 **4.56:1**。这些数值只是指定色值组合的计算结果，不代表完整无障碍审计。

默认内容无投影。只有搜索、手机菜单和预览提示可使用 `--shadow-overlay` / `--shadow-notice`，避免浮层与底层混淆。

## 03 · 字体与层级

系统字体优先；不打包字体，不请求网络字体。

```css
font-family:
  -apple-system, BlinkMacSystemFont, "Segoe UI",
  "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei",
  "Noto Sans CJK SC", sans-serif;
```

| 元素 | 桌面字号 / 行高 | 手机字号 / 行高 | 字重 |
|---|---|---|---|
| 站名 | 19px / 1.6 | 18px / 1.6 | 600 |
| 顶部导航 | 14px / 24px | 菜单内同桌面 | 400 |
| 首页主标题 | 38px / 50px | 30px / 42px | 600 |
| 首页介绍 | 17px / 28px | 15px / 26px | 400 |
| 区块标题 | 21px / 30px | 20px / 30px | 600 |
| 导读标题 | 16px / 26px | 15px / 24px | 600 |
| 导读说明 | 14px / 23px | 13px / 22px | 400 |
| 文章标题 | 16px / 26px | 16px / 26px | 500 |
| 文章摘要 | 14px / 24px | 13px / 23px | 400 |
| 文章元信息 | 13px / 22px | 12px / 20px | 400 |
| 分类按钮 | 14px / 24px | 同桌面 | 500 |
| 专题标题 | 16px / 24px | 同桌面 | 500 |
| 专题说明 | 13px / 21px | 同桌面 | 400 |
| 查看专题 | 12px / 20px | 同桌面 | 400 |
| 页脚 | 12px / 20px | 11px / 20px | 400 |

主标题字距 `-0.025em`，区块标题 `-0.015em`，站名 `0.03em`。中文文章正文不额外收紧字距。日期和阅读时长使用 `font-variant-numeric: tabular-nums`。

分类的选中与未选中状态使用相同字重，仅改变文字颜色与下划线，避免切换时文字宽度变化。

手机介绍拆成两句展示：第一行「记录学习与实践，」，第二行「分享值得反复阅读的方法与经验。」。导读说明的两个短句使用独立行内块，空间不足时整句换行，不把末尾几个字挤到单独一行。

小于 360px 时，介绍和导读标题降至 14px；文章标题仍保持 16px，并允许自然换行。

## 05 · 文章列表规范

宽屏保留参考图的横向结构，使用三条稳定的文字列线：

```text
文章标题（320px）  ← 24px →  摘要（自适应）  ← 20px →  元信息  ← 20px →  箭头
```

标题列固定 320px；摘要占用剩余空间。不要将摘要直接拼接在标题之后，避免每一行从不同位置开始。

标题保持完整，超长标题自然换行。桌面摘要空间不足时单行省略；手机摘要最多两行。元信息顺序保持「分类 · 日期 · 阅读时长」。

整行只有一个主要点击目标，不嵌套收藏、点赞或其他按钮。不加缩略图、头像、彩色标签或阅读量。

悬停背景由伪元素实现：左右向外延伸 12px、上下内收 3px；手机左右延伸 8px。文字仍保持原位置，分隔线也不移动。键盘焦点时同样显示浅背景，并叠加清晰的焦点轮廓。

## 06 · 搜索、图标与边界

| 组件 | 规范 |
|---|---|
| 桌面搜索入口 | 最小宽 136px，高 34px；1px 边框，6px 圆角 |
| 搜索键帽 | 10px 文字；1px 边框，下边框 2px；不使用额外投影 |
| 导读块 | 8px 圆角；无外边框、无阴影、无强调色侧边条 |
| 专题卡片 | 1px 边框；8px 圆角；无默认阴影 |
| 专题图标底座 | 44 × 44px；9px 圆角方形；内部图标 24px |
| 图标与专题文字 | 桌面间距 18px，手机 16px |
| 搜索弹层 | 最大宽 560px；10px 圆角；限制高度，内容可滚动 |
| 手机搜索与菜单 | 各 44 × 44px 点击区域 |

功能图标使用内联 SVG，常规 `viewBox="0 0 24 24"`，线宽为 1.6 个 SVG 坐标单位，端点和转角圆润。书本图标线宽为 1.55；品牌保留 24 × 26 坐标系与 1.9 线宽，属于品牌专用例外。

图标不混用彩色 Emoji。缩小的是图标视觉尺寸，不是手机按钮的点击区域。

## 07 · 响应式规则

| 视口 | 布局规则 |
|---|---|
| ≥ 1160px | 标题、摘要、元信息横排；摘要统一起点；专题两列 |
| 801–1159px | 标题与摘要在左侧上下排列，元信息在右；专题两列 |
| 641–800px | 保留中屏布局，右侧阅读时长可独占一行；缩小专题内部间距 |
| ≤ 640px | 导航变为站名、搜索、菜单；文章信息上下排列；专题单列 |
| < 360px | 进一步收紧导读与分类间距；不缩小文章标题 |

移动端不是桌面截图等比缩放。箭头独立占位；文字自然排版。优先完整展示标题，摘要可以省略。

正文、导航与页脚都使用正常文档流，不固定整页尺寸、不使用截图背景、不绝对定位拼出整个界面。

## 08 · 状态与交互

所有微过渡采用 **160ms** 与 `cubic-bezier(.2, .7, .2, 1)`。

悬停时，文章行只改变底色，末尾箭头向右移动 2px；专题改变浅底色和边框，图标颜色略加深。次级文字链接出现细下划线，箭头同样移动 2px。整行、整卡和文字不浮起、不放大。

悬停规则限定在 `hover: hover` 且 `pointer: fine` 的设备。触屏按下有即时背景反馈，不依赖悬停才出现关键操作。

键盘焦点采用 2px 轮廓，通常向外偏移 4px；分类为 2px。搜索结果焦点向内偏移，避免被滚动容器裁切。

尊重 `prefers-reduced-motion: reduce`，关闭平滑滚动和 CSS 过渡。页面不使用循环动画或自动入场动画。

保留的首页交互：分类筛选与重置、本页锚点、手机菜单、本地搜索、搜索空态、键盘选择、Esc 关闭、关闭后的焦点恢复，以及未接入详情入口的明确预览提示。搜索只检索首页五条示例内容。

## 09 · 实现边界

`高保真/index.html` 是单文件实现，包含 CSS、内联 SVG 和原生 JavaScript，不引用外部样式、图片、字体或脚本。无需构建工具、安装依赖或连接后端。

仅交付首页，不包含文章正文、专题详情、关于正文、RSS 服务、用户体系或内容管理。导读入口在本原型中重置分类并定位文章列表，不虚构阅读指南正文。尚未接入的详情入口会显示提示，不跳往不存在的页面。

示例内容保存在 HTML 的 `#article-list` 中。本地搜索直接读取 DOM，不维护第二份内容数据。修改视觉参数优先调整 `:root`；修改文章只改对应列表项。
