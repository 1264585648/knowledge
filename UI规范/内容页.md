# 知页 · 三栏内容页

对应高保真：`高保真/article.html`。对应站点：`site/src/pages/articles/[id].astro`。

## 设计定位

左侧负责定位，中间负责阅读，右侧负责提问、讨论与记录。沿用首页的近白画布、暖灰文字、细边框、系统字体与轻量反馈；正文不使用封面大图、渐变、默认投影或虚构阅读量。示例文章为《什么是 RAG：让大模型先查资料，再回答》，按「为什么需要 RAG / 什么是 RAG / RAG 能用在哪里」组织，参考资料直接链接到原始论文和官方说明。

## 布局

- 大于 1100px：三栏。容器最大 1320px；左侧 176px，右侧 304px，间距 36px，中间自适应，正文最大 720px。1101–1200px 收紧为左侧 150px、右侧 280px、间距 24px。侧栏 sticky，内部允许滚动。
- 761–1100px：目录 + 正文两栏；右侧工具通过浮动按钮打开侧边弹层。
- 不大于 760px：单栏；目录折叠，工具以底部面板展开。左右留白 20px，不压缩成三条窄列。
- 文章标题桌面 36px，手机 29px；正文 15px / 1.95，二级标题 23px，工具区使用较小字号，保持正文的视觉优先级。
- 所有颜色复用 `UI规范/README.md` 的语义 token。只有浮层和提示允许轻投影。减少动态效果偏好与打印样式已覆盖。

## 页面结构与交互

左侧包含所属专题、二三级目录、当前阅读位置和回顶部。目录取自 Astro 渲染的 headings；静态示例也保留原生锚点。禁用脚本时仍可阅读并使用目录。

正文包含面包屑、专题与示例标识、标题、摘要、日期、估算阅读时长、导读、三章内容、简化流程图和参考资料。阅读时长是按 Markdown 非空白字符估算的编辑参考值，不是阅读统计。提供专注阅读、复制链接、打开笔记。选中文字（最多 1500 字符）可带着原文进入提问或笔记，并保留章节位置。

右侧「边读边想」使用提问 / 评论 / 笔记三个标签。标签支持左右方向键、Home、End。手机弹层支持焦点约束、背景 inert、Escape 关闭及焦点归还；跨断点恢复滚动和可访问性。

## 功能状态，不制造假完成

| 能力 | 本次实现 |
| --- | --- |
| 目录、锚点、高亮、专注阅读 | 实际可操作 |
| 提问 | 本地交互演示；显示问题和明确标注的原文摘录，不生成 AI 回答、不发送请求 |
| 评论 | 本页临时添加/删除，刷新清空；不公开发布、不伪造其他用户评论 |
| 笔记 | 显式保存、编辑、删除、原文摘录、章节链接、Markdown 导出 |
| 持久化 | 当前浏览器的 localStorage，以文章 ID 分开；不可用或损坏时明确告警，不报虚假成功 |
| 服务端 | 没有新增问答、评论或笔记 API，也没有修改既有关注验证与访问控制 |

笔记不是跨设备或账号隔离的私密云存储。页面明确提醒：同一浏览器的其他使用者也可能看到，不要记录敏感内容；清理浏览器数据会丢失笔记，建议导出。单篇最多 200 条笔记；多标签同时编辑不具备冲突合并。生产接入账号笔记时应重新设计权限、用户隔离与同步，而不是直接复用本地存储键。

所有用户输入均通过 `textContent` 渲染。存储读写有异常处理，加载时验证数据形状；存储损坏时不覆盖原数据。删除笔记需确认。编辑器有未保存内容时，尝试在离开页面前提醒（依赖浏览器支持）。

## 文件与预览

- `高保真/article.html`：打开即可查看，依赖仓库内 `site/public/public/article-reader.css` 和 `.js`；保留整个目录结构，或从仓库根目录启动静态服务器。
- `site/src/components/ArticleReader.astro`：可复用三栏阅读组件，通过 slot 接收文章正文。
- `site/src/components/ReaderTools.astro`：右侧三标签工具。
- `site/content-example/what-is-rag.md`：公开演示文本；开发时进入 `/articles/what-is-rag/`，并出现在知识管理专题中。
- `高保真/tests/article_reader_test.py`：本地 DOM 冒烟测试。

`sample: true` 是示例标记，不改变 Worker 的路由权限。生产模式使用独立内容目录时，应按既有发布流程导入需要的文章，不应为了预览示例放开站点权限。高保真是公开设计样例，不包含私有资料。
