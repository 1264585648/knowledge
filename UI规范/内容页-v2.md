# 知页 · 参考图内容页 v2

对应实现：`高保真/article-v2.html`。这是用户确认的截图方案，不替换 `高保真/article.html`，也不修改 `site/` 工程及关注验证逻辑。

## 版式

左侧是全站专题与文章树，中间是文章正文，右上是本篇目录，右下是提问 / 批注。桌面画布最大 1480px；宽屏左右栏各 320px，中间剩余空间分配给正文，正文左右各留 34px，1586px 视口下正文内容宽 770px。顶部操作条高 56px。两侧保持定位，超出视口时各自可滚动。

1439px 以下逐级收紧侧栏。1100px 以下为专题目录 + 正文两栏，右侧工具通过抽屉打开；820px 以下只保留正文，底部提供专题目录、本篇目录、提问 / 批注入口。抽屉使用原生 dialog，支持焦点约束、Escape 关闭，以及跨断点恢复原 DOM 位置。手机正文左右至少 18–22px 留白。

继承 `UI规范/README.md` 的颜色 token、系统字体、细边框和轻反馈。按本次参考图新增暖金色 `--accent`，只用于当前位置、引用侧线和阅读进度。本版本明确采用截图中的横幅，与旧内容页“不使用大图”的约定分开管理。无第三方字体、脚本或 CDN 依赖。

## 内容与图像

公开示例文章《什么是 RAG：让大模型先查资料，再回答》包括五个主章：为什么需要 RAG、什么是 RAG、工作原理、应用场景、小结。附原始论文和官方文档链接；制度问答明确为人为构造的示例。阅读时间由正文字符数 / 350 向上取整，仅为编辑估算。

`assets/rag-reading-cover.webp` 从用户提供的参考图中裁取，768 × 222px，约 9.7 KB，不含整张界面截图。图片上的书本与文案保留原貌。它是设计预览素材，不应被误认为重新制作的超高清原图；正式发布时可换成对应的授权高清原始素材。

## 可操作范围

- 全站专题展开 / 收起、当前文章高亮、真实本篇锚点、随滚动高亮和顶部进度。
- 本文搜索，以及原型内专题 / 文章目录搜索；Ctrl / Cmd + K、方向键、Enter、Escape 可操作。未接入的文章明确展示待接入状态，不跳转到不存在的页面。
- 收藏、最近阅读、深浅色切换、专注阅读、复制链接、打印与回到顶部。
- 选中正文可带原文提问或添加批注。提问仅当前页面临时展示，刷新清空，不发送请求、不生成 AI 回复。预置讨论逐条标注为示例。
- 批注支持本地保存、引用原文、编辑、确认删除和 Markdown 导出；与旧原型使用不同存储键。页内草稿跨标签保留，离开页面时尝试提醒。

本地存储不是私密账号空间，也不跨设备同步；同一浏览器使用者可能看到批注。存储损坏、访问受限、容量不足或其他标签页改变数据时，不宣称持久保存成功，也不覆盖损坏数据，而是提示本页暂存并建议导出。最多 200 条批注；输入全部通过 textContent 渲染。

## 文件与运行

```text
高保真/article-v2.html

```

保留目录结构后可直接打开 HTML。为获得稳定的浏览器存储来源，建议从仓库根目录启动本地静态服务器：

```bash
python -m http.server 8000
# 打开 http://localhost:8000/高保真/article-v2.html
```

首页与全部内容沿用同目录的 `index.html`、`topics.html`。本版本尚未替换正式 Astro 页面，也没有新增接口或部署 Cloudflare。不得以这个公开原型替代服务端权限控制。
