## 这篇文章只提供内容

这份文件没有页面 HTML、专用 CSS 或交互脚本。标题、摘要、专题和篇次来自文件头；正文从二级标题开始。它没有配置封面，因此不会出现空白横幅占位。

> 这是用于模板验收的公开示例，不代表正式课程的下一篇。

### 目录来自标题

修改本节标题并重新构建后，右侧目录与锚点会随正文变化。三级目录由文件头的 `tocDepth: 3` 控制。

### 阅读顺序来自篇次

示例的 `order: 2` 排在首篇后面。正式写第二课时，可以删除本样例，新增一份真实文章，而不修改页面组件。

## 常用正文排版

| 内容 | 写作方式 | 页面表现 |
| --- | --- | --- |
| 重点 | 双星号 | **关键结论** |
| 引用 | 行首大于号 | 暖灰引用块 |
| 代码 | 三个反引号 | 可横向滚动的代码块 |

下面的命令从 `site` 目录运行，仅创建草稿，不会发布：

```bash
npm run new:article -- rag-next-lesson --topic rag --order 3 --title "我的下一篇文章"
```

## 验证文章之间的数据隔离

在这篇文章保存一条批注，再进入《什么是 RAG》。两篇文章不应显示对方的笔记；回到本篇后，已保存的内容仍然属于本篇。

### 同一浏览器，不等于私密账号

这些阅读工具只使用当前浏览器存储，不跨设备同步。不要记录敏感信息，清理浏览器数据前请先导出批注。

## 下一步怎么写

复制 `site/templates/article.md`，或者使用上面的新建命令。日常只需编辑文章信息和 Markdown 正文，页面骨架仍然是同一份。
